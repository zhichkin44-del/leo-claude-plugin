# Leo

**Leo не даёт Claude Code потерять нить: после сжатия контекста возвращает окна, обещания и правила, а перед итоговым ответом Haiku-скептик проверяет, нет ли в нём непроверенного.**

[English](README.md) · MIT · Node.js 18+ · Windows, macOS, Linux · без зависимостей

## Установка

Нужны Claude Code и Node.js 18+.

```bash
claude plugin marketplace add zhichkin44-del/leo-claude-plugin
claude plugin install leo@leo-marketplace
```

На Claude Code 2.1.292+ хватит одной строки: `claude plugin install leo --marketplace zhichkin44-del/leo-claude-plugin`.

Начните новую сессию и выполните `/leo:doctor`: он проверит Node, `claude` в PATH, хуки, права на файлы и настройки и подскажет, что исправить.

## Что делает

После сжатия контекста Claude забывает, что происходило. Leo возвращает главное (не больше 40 строк): ваши открытые задачи, последнюю просьбу, устойчивые указания («всегда…», «никогда…»), недавно тронутые файлы и, если вы их ведёте, сессии и их статус, что ждёт решения, правила и обещания.

**Работает из коробки.** Перед сжатием (PreCompact) и при старте сессии Leo сам читает транскрипт и собирает это: без настройки, без ручных записей, без вызова модели. Состояние хранится по `session_id`, поэтому два окна не видят задач друг друга.

Перед итоговым ответом Leo просит Claude Haiku (один вызов, без инструментов, один ход) прочитать его в двух ролях:

- **читатель**: простыми ли словами, коротко ли, нет ли непояснённого жаргона, ясно ли, что делать вам;
- **скептик**: не утверждается ли «сделано / слито / работает» без доказательств, не брошено ли обещанное, не нарушены ли ваши правила.

Серьёзная находка возвращает ответ на один круг доработки (`mode: block`) или только подсказывает (`mode: advice`). В остальном Leo молчит.

## Зачем Leo

- **Лёгкий и прозрачный.** Нет базы данных, фоновых процессов, хука на каждое сообщение, нет зависимостей. Четыре события хуков (ни одного на каждое сообщение) и несколько файлов, которые читаются за десять минут.
- **Проверяет ответ, а не только хранит память.** Большинство плагинов сжатия сохраняют и возвращают состояние. Leo ещё и проверяет итоговый ответ, с защитой от петли: один вызов Haiku и один круг блокировки на ответ, внутренний вызов не запускает Leo повторно.
- **Честен с секретами.** Фильтр маскирует значения (не пути) перед записью, возвратом и отправкой в Haiku. Это страховка, а не гарантия.

Не подходит, если нужна память между проектами и поиск по истории: берите claude-mem. Leo — про то, чтобы одна длинная сессия оставалась честной и не теряла нить.

## Что уходит наружу

У Leo нет сервера и телеметрии, он сам не делает сетевых вызовов. Наружу уходит только вызов Haiku через **ваш собственный установленный `claude`, под вашим аккаунтом**:

- итоговый ответ ассистента, до **8000 знаков** (длиннее — середина обрезается);
- ваши **3 последних сообщения** из транскрипта сессии;
- ваши правила за сегодня и открытые обещания, которые Leo хранит.

Всё это сначала проходит фильтр секретов. Ответы короче 120 знаков не отправляются никогда; от 120 до 599 знаков — только со словами-утверждениями («сделано», «слито», «done», «fixed»…). Когда Leo выключен, не отправляется ничего.

Локально Leo хранит в `~/.claude/leo/` (или `$LEO_HOME`): `state.json` (сессии, ожидание, обещания, правила; тексты до 300 знаков, с фильтром), `leo.log` (вердикт, число находок, время, цена; текстов ответов нет), `config.json` (ваш) и файл-выключатель `off`. На macOS и Linux файлы создаются с правами 0600; на Windows наследуют права вашего профиля. Журнал выключается через `"log": false` или `LEO_NO_LOG=1`.

То же самое печатает `leo doctor`. Выключить Leo: `/leo:off`.

## Настройки

Создайте `~/.claude/leo/config.json`. Все ключи необязательны; схема — в [`docs/config.schema.json`](docs/config.schema.json), её проверяет `leo doctor`.

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `lang` | по локали, иначе `en` | `en` или `ru`: язык сообщений Leo и запроса к Haiku (`LEO_LANG` важнее) |
| `mode` | `advice` | `advice` только подсказывает; `block` возвращает ответ на доработку (`LEO_MODE`) |
| `minLength` | `600` | ответы такой длины проверяются и без слов-утверждений (`LEO_MIN_LENGTH`) |
| `triggers` | `[]` | свои слова-утверждения |
| `model` | `haiku` | модель проверки (`LEO_MODEL`) |
| `maxCostPerDay` | `0` | доллары в сутки, `0` — без лимита |
| `roles` | обе `true` | отключить `reader` или `skeptic` |
| `ruleTtlDays` | `1` | сколько дней живёт правило, добавленное `rule add` |
| `autoCollect` | `true` | собирать задачи, последнюю просьбу, указания и файлы из транскрипта |
| `log` | `true` | вести `leo.log` |
| `sources` | `{}` | необязательные файлы `status`, `handoffDir`, `memoryIndex`, которые Leo тоже читает |
| `profile` | `default` | `director`: личный русский словарь автора |

Переменные окружения: `LEO_HOME`, `LEO_OFF=1` (хуки молчат), `LEO_NO_LOG=1`, `LEO_HAIKU_TIMEOUT_MS` (по умолчанию 45000), `LEO_CLAUDE` (полный путь к `claude`).

## Команды

Внутри Claude Code: `/leo:show` (что Leo вернул бы сейчас), `/leo:status`, `/leo:doctor`, `/leo:off`, `/leo:on`.

Из терминала: `node "<папка плагина>/bin/leo.mjs" <команда>`:

```
show | status | log [n] | doctor [--ping] | off | on
window set <имя> <статус> [заметка] | window drop <имя>
wait add <текст> | wait done <id>
promise add <текст> | promise done <id>
rule add <текст> | rule drop <id>
```

`log` показывает последние вердикты, число блоков, общую цену и среднее время. `doctor --ping` делает один настоящий мелкий вызов Haiku и сообщает время и цену.

## Если не работает

Сначала `/leo:doctor`: у каждой строки `[ИСПР]` написано, что делать.

- **«claude не найден в PATH»**: хуки иногда запускаются с более коротким PATH, чем в терминале (IDE, десктопное приложение). Добавьте папку с `claude` в PATH или задайте `LEO_CLAUDE` полным путём. Без этого проверка ответа молча не работает.
- **«нет флага --safe-mode»**: обновите Claude Code (`claude update`).
- **«Не могу писать в ...»**: исправьте права на `~/.claude/leo` или задайте `LEO_HOME` на доступную папку.
- **После сжатия возвращается мало**: Leo возвращает то, что видно в транскрипте (открытые задачи `TodoWrite`, последняя просьба, указания «всегда/никогда», правленые файлы), плюс записи командами выше. Если в сессии не было списка задач и таких указаний, возвращать почти нечего. Проверьте `/leo:show`; `"autoCollect": false` выключает сбор.
- **Медленно**: проверка добавляет около 8–11 с к длинному итоговому ответу (замер на Windows с прямым `claude.exe`; около 22 с через `claude.cmd`). Используйте `"mode": "advice"`, увеличьте `minLength` или `"roles": {"reader": false}`.

## Ограничения

- Для проверки ответа нужен `claude` с входом в аккаунт и сеть.
- Проверка вероятностная: Haiku может пропустить находку или придраться зря. Серьёзная находка даёт один круг блокировки, дальше ответ уходит.
- Автосбор эвристический: он видит открытые задачи `TodoWrite`, последнее содержательное сообщение пользователя, предложения со словами always/never/всегда/никогда и последние правленые файлы. Разговор он не понимает; важное фиксируйте через `rule add`, `wait add`, `promise add`.
- Хук `PostCompact` только пишет запись в журнал; сам возврат делает `SessionStart` с matcher `compact`.
- Тесты разработаны на Windows; macOS и Linux покрывает CI-файл `.github/workflows/ci.yml` (3 системы × Node 18/20/22), он запустится после первого пуша.
- Фильтр секретов — страховка: он знает частые форматы токенов и строки `KEY=value`, но не все секреты на свете.

## Вклад

`npm test` запускает всё с подставным `claude` (`tests/fake-claude.mjs`), без сети. Новое правило фильтра — в `lib/secrets.mjs` плюс положительный и отрицательный образцы в `tests/secrets.test.mjs`. Тексты лежат в `lib/i18n.mjs`; тест проверяет, что у английского и русского одинаковые ключи.
